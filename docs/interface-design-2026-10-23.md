# 基建调度界面改版

## 参考

- [明日方舟官网](https://ak.hypergryph.com/)：实际浏览首页，参考明确的分区、硬边界、大标题与克制的辅助文字，不复制官网插图或布局。
- [no-slop-ui](https://github.com/LeoStehlik/no-slop-ui)：以真实产品操作为主，减少卡片套卡片、装饰性渐变和虚假指标。
- [Refero anti-AI-slop](https://github.com/referodesign/refero_skill/blob/master/skills/refero-design/references/anti-ai-slop.md)：保持单一设计方向，让颜色、排版与留白有实际用途。

## 界面约定

以浅灰工作台、黑色导航、黄色主操作构成基础视觉；保留用户已保存的深浅主题偏好，新用户默认浅色。A/B 班分别使用青灰和蓝灰，负收益使用红色。卡片只承担必要分区，指标、设施、产出明细主要依靠间距和分隔线组织。

计算前显示当前配置的真实设施预览；上线间隔直接可见。计算按钮固定在设置栏底部，计算中的真实阶段与耗时持续更新，完成后折叠用时明细。

计算后默认打开轮换排班。同一设施的 A/B 班横向对照；手机上纵向排列。配队基准日产和在岗时长直接显示，工时占比、技能机制与配队原因在明细中展开。长时间轴默认以 200% 横向缩放显示，支持 100%–400% 手动调整，6–8 小时的三人班次也能显示头像。时间轴独立横向滚动，设施名与日期轴固定，短时段显示班组人数而不挤压头像。技能浮窗保留延迟打开、离开关闭和全组技能按钮。

干员管理保留草稿、职业/分支筛选、排序、拖动、精英图标与等级编辑。排班算法、接口参数、原始收入与模拟结果不变；主指标中的龙门币、经验取整数显示，详细数据保留原精度。

## 验证

使用忽略目录中的真实历史排班结果，在独立本地预览服务验证界面；不为视觉验证重新运行数分钟的优化器，也不覆盖干员名单。检查桌面与 390 px 视口、深浅主题、设施对照、干员弹窗与技能详情。自动回归覆盖设施配对、单班和辅助设施保留、原始结果不变，以及现有浮窗、干员操作与前后端元素契约。
